전화 앱이야, 자유로운 주제로 대화하고 싶은 사람들이 모여서 통화하는 서비스야

1. 서비스 개요
1-1. 서비스 콘셉트

서비스 이름(가칭): 자유통화(가칭) / FreeTalk 등

한 줄 정의:
“나와 잘 맞는 상대와, 서로 원하는 시간에, 자유로운 주제로 통화하는 1:1 음성 대화 플랫폼”

핵심 포인트

남녀가 서로 관심사·언어·나이를 보고 선택해서 통화

“지금 바로 통화” 또는 “특정 시간대에 통화 예약”

**분당 요금을 받는 ‘통화 받는 유저’**와
포인트를 사용해 통화하는 ‘통화 거는 유저’ 구조

익명성 + 후기/별점 기반 신뢰도 시스템

1-2. 타깃 유저

통화를 받는 유저(호스트, 리스너, 상담자 등)

목소리 소통/수다/상담을 좋아하는 사람

언어 연습, 고민 상담, 친구 만들기 등으로 수익을 얻고 싶은 사람

본인 프로필을 등록하고, 분당 통화 요금을 스스로 설정

통화 요청 유저(게스트, 콜러)

심심풀이, 고민 나눔, 언어 교환, 취미 이야기 등

자기 취향의 프로필을 보고, 통화 요청 후 포인트로 결제

3. 주요 비즈니스 룰
3-1. 포인트 & 결제

충전 단위

최소 충전: 10,000원 단위

충전 패키지

10,000원 → 10,000 포인트

30,000원 → 40,000 포인트 지급 (10,000 보너스)

100,000원 → 150,000 포인트 지급 (50,000 보너스)

포인트 사용

통화 요청 1회당 200 포인트 차감

통화 진행 시, 통화 받는 사람의 분당 요금에 따라 포인트 차감

통화 전 포인트 체크

통화 시작 시:

현재 보유 포인트 / 분당 요금 → 최대 통화 가능 시간(분) 계산

예: 보유 6,000P, 분당 300P → 최대 20분

최대 가능 시간 도달 시 자동 통화 종료

3-2. 통화 요금 설정 (통화 받는 사람 기준)

각 유저는 본인의 분당 통화 요금을 설정 가능 (예: 분당 200P, 300P, 500P 등)

관리자가:

최소/최대 분당 요금 범위 설정 가능 (예: 100P~1,000P)

특정 유저에 대한 요금 상·하한 제한/조정 가능(향후 고도화 포인트)

3-3. 통화 요청 & 예약

통화 요청 타입

“지금 바로 통화 요청”

“00시~00시 사이 통화 원함 (예약 요청)”

수신자(통화 받는 사람)의 응답

지금 통화 수락 → 즉시 연결

예약 요청 수락:

(예: 20:30~21:00)
